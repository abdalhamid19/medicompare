## الخطة التفصيلية — 7 مراحل

---

### المرحلة 1: تنظيف بيانات الإدخال (زيادة المطابقات المحتملة بـ ~82)

**المشكلة**: 82 صنف تبدأ بـ `+***IMP` أو `+***imp` مما يمنع الـ normalizer من استخراج العلامة التجارية بشكل صحيح.

**الحل**:
1. تحسين `normalize()` ليزيل أي بادئة تحتوي على `IMP` أو `+***` بشكل كامل
2. حالياً يزيل `IMP` لكن البادئة `+***` تبقى أحياناً
3. إضافة regex: `re.sub(r'^[+*.]+\s*(IMP\s*(IMPORTED\s*)?)?', '', name)`

**مثال**:
- `+***IMP PANADOL NIGHT 20 TAB` ← `PANADOL NIGHT 20 TAB` ← يُطابق بنجاح

**النتيجة المتوقعة**: +30-50 مطابقة جديدة

---

### المرحلة 2: تحسين استخراج المكونات (زيادة المطابقات بـ ~200)

**المشكلة 2A**: أسماء الأدوية بدون مسافات بين الجرعة والوحدة
- `PANADOL20MG` بدل `PANADOL 20 MG`
- الـ regex لا يلتقطها

**الحل**: إضافة regex لفصل الأرقام عن الحروف:
```python
name = re.sub(r'(\d)([A-Z])', r'\1 \2', name)  # 20MG → 20 MG
name = re.sub(r'([A-Z])(\d)', r'\1 \2', name)  # PANADOL20 → PANADOL 20
```

**المشكلة 2B**: الكمية مدمجة مع الشكل
- `30TAB` بدل `30 TAB`
- `28CAP` بدل `28 CAP`

**الحل**: نفس الحل أعلاه — فصل الأرقام عن الحروف قبل التحليل

**المشكلة 2C**: الصيغ غير القياسية
- `21-CAP` بدل `21 CAP`
- `10TABS` بدل `10 TABS`

**الحل**: إزالة الشرطات قبل التحليل:
```python
name = re.sub(r'-', ' ', name)
```

**النتيجة المتوقعة**: +100-200 مطابقة جديدة

---

### المرحلة 3: تخفيض عتبة المطابقة مع تحقق أقوى (زيادة ~300-500)

**المشكلة**: العتبة الحالية 80% ترفض تطابقات صحيحة بنسبة 70-79%.

**الحل**: 
1. تخفيض `fuzzy_threshold` من 80 إلى 65
2. الاعتماد على `components_match` كفلتر أساسي بدل النسبة
3. إذا تطابقت العلامة التجارية + الجرعة + الكمية = مطابق صحيح حتى لو النسبة 65%

**التنفيذ**:
```python
# في indexer.py best_match():
# Strategy 3: Lower threshold with strict component verification
if not best:
    for scorer in [fuzz.token_set_ratio, fuzz.token_sort_ratio]:
        result = process.extractOne(norm, self._norms, scorer=scorer, score_cutoff=65)
        if result:
            match_name, score, idx = result
            is_ok, reason = components_match(parsed, self._parsed_cache[idx], self._cfg.brand_prefix_min)
            if is_ok and reason == "ok":
                # Extra check: brand must match well
                if fuzz.ratio(parsed.brand, self._parsed_cache[idx].brand) >= 70:
                    if best is None or score > best[1]:
                        best = (self._records[idx], score, scorer.__name__)
```

**النتيجة المتوقعة**: +300-500 مطابقة جديدة

---

### المرحلة 4: مطابقة المكون النشط (زيادة ~200-400)

**المشكلة**: كثير من الأدوية تُسمى بالمادة الفعالة (مثل `OMEPRAZOLE 20 MG`) بينما في التوريد تُسمى بالعلامة التجارية (مثل `OMEPRAZOL 20 MG`). الـ fuzzy يلتقط بعضها لكن ليس كله.

**الحل**: بناء قاموس مكون نشط ← علامات تجارية:
1. استخراج الأسماء التي تبدأ بمادة فعالة (ليس لها علامة تجارية واضحة)
2. البحث في التوريد عن أسماء تحتوي نفس المادة الفعالة
3. المطابقة بالجرعة والشكل فقط (بدون علامة تجارية)

**التنفيذ**:
```python
# قائمة المواد الفعالة الشائعة (من الأدوية غير المطابقة)
ACTIVE_INGREDIENTS = {
    "OMEPRAZOLE", "AMOXICILLIN", "CIPROFLOXACIN", "METFORMIN",
    "ATORVASTATIN", "CLOPIDOGREL", "LOSARTAN", "AMLODIPINE",
    "PANTOPRAZOLE", "FLUCONAZOLE", "ACETYLCHOLINE", ...
}

# في best_match():
# Strategy 4: Active ingredient matching
if not best and parsed.brand in ACTIVE_INGREDIENTS:
    # Search for products containing this ingredient
    for idx, tcomp in self._parsed_cache.items():
        if parsed.brand in tcomp.normalized:
            if components_match_dosage_only(parsed, tcomp):
                score = fuzz.token_sort_ratio(norm, self._norms[idx])
                if score >= 60:
                    best = (self._records[idx], score, "active_ingredient")
                    break
```

**النتيجة المتوقعة**: +200-400 مطابقة جديدة

---

### المرحلة 5: تحسين الـ AI Verifier (رفض الخاطئ + إيجاد البديل)

**المشكلة الحالية**: الـ AI (gemini-flash) يؤكد كل شيء ولا يرفض شيئاً.

**الحل 5A**: استخدام نموذج أقوى:
- التبديل من `~google/gemini-flash-latest` إلى `google/gemini-2.5-flash-preview` أو `anthropic/claude-3.5-sonnet`
- النموذج الأقوى يفهم الفروق الدقيقة أفضل

**الحل 5B**: تحسين الـ prompt مع أمثلة سلبية:
```
Examples of WRONG matches:
- "VIGOTON PLUS 20 TABS" ≠ "VIGOTON 30 TABS" (PLUS missing, qty different)
- "GYNOCONAZOLE 0.8%" ≠ "GYNOCONAZOL 0.4%" (dosage different)
- "CLOZAPINE 100 MG 30 TABS" ≠ "CLOZAPEX 100 MG 50 TAB" (brand AND qty different)
- "TOTAL COD LIVER OIL 120 ML SYP" ≠ "TOTAL SYRUP 120 ML" (different product)

Examples of CORRECT matches:
- "AUGMENTIN 625MG 10 TABS" = "AUGMENTIN 625 MG 10 F.C. TAB." (same product, minor formatting)
- "INDERAL 10 MG 50TAB" = "INDERAL 10 MG 50 TABS" (same product)
```

**الحل 5C**: التحقق الخوارزمي المسبق قبل الـ AI:
- إذا `components_match` يرفض = رفض مباشر بدون إرسال للـ AI
- إذا `components_match` يقبل = إرسال للـ AI للتأكيد النهائي
- هذا يوفر تكلفة الـ API ويزيد الدقة

**الحل 5D**: تصويت الأغلبية (Majority Vote):
- إرسال نفس التطابق لـ 3 نماذج مختلفة
- اعتماد نتيجة الأغلبية
- يقلل الأخطاء بشكل كبير

**النتيجة المتوقعة**: رفض ~200-400 تطابق خاطئ من الـ 1,977 (80-89%) + إيجاد بدائل صحيحة

---

### المرحلة 6: المطابقة العربية (زيادة ~100-200)

**المشكلة**: بعض الأدوية لا تتطابق بالإنجليزية لكن الاسم العربي يتطابق.

**الحل**:
1. إضافة عمود الاسم العربي من ملف الأدوية (إذا متوفر)
2. مطابقة fuzzy على الأسماء العربية
3. التحقق بالإنجليزي كـ fallback

**التنفيذ**:
- إضافة `arabic_match()` في `DrugIndex`
- استخدام `rapidfuzz` على الأسماء العربية
- دمج النتائج مع المطابقة الإنجليزية

**النتيجة المتوقعة**: +100-200 مطابقة جديدة

---

### المرحلة 7: المراجعة اليدوية + التعلم (الخطوة الأخيرة لـ 100%)

**المشكلة**: حتى بعد كل التحسينات، سيبقى ~500-900 صنف غير مطابق (علامة تجارية غير موجودة في التوريد).

**الحل 7A**: تصنيف غير المطابقين:
1. **غير موجود في التوريد فعلاً** ← يُعلّم كـ `NOT_AVAILABLE`
2. **موجود لكن الـ algorithm فشل** ← يُرسل للمراجعة اليدوية
3. **بيانات ضوضاء** ← يُعلّم كـ `INVALID_DATA`

**الحل 7B**: واجهة مراجعة يدوية:
- صفحة HTML بسيطة تعرض كل تطابق مشبوه
- المستخدم يضغط ✅ أو ❌
- النتائج تُحفظ وتُستخدم كـ training data

**الحل 7C**: التعلم من المراجعة اليدوية:
- تحليل أنماط الأخطاء
- تحسين الـ regex والـ thresholds بناءً على البيانات
- بناء قاموس استثناءات للعلامات التجارية المشابهة

## خطة التنفيذ الفوري (المرحلتين 1+2+3)

هذه الخطوات يمكن تنفيذها الآن بدون تكلفة وبأثر كبير:

1. **تحسين `normalize()`**: إزالة `+***IMP` بشكل كامل + فصل الأرقام عن الحروف
2. **تحسين `_QTY_RE`**: دعم صيغ مثل `30TAB`, `28-CAP`
3. **تخفيض `fuzzy_threshold`** من 80 إلى 65 مع تحقق `components_match` صارم
4. **إضافة تحقق خوارزمي قبل AI**: لا ترسل للـ AI ما يرفضه `components_match`
5. **إعادة تشغيل الـ pipeline** ومراجعة النتائج
